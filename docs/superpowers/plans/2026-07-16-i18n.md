# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm đa ngôn ngữ (vi/en) cho LemonChat theo pattern SplitDebt — locale JSON, react-i18next, language switcher, localStorage persistence.

**Architecture:** react-i18next với static import locale bundles, LanguageProvider context quản lý locale state + persistence, tách translation keys theo feature namespace (auth, common, layout).

**Tech Stack:** react-i18next, i18next, localStorage

**Spec:** Pattern từ `/home/nguien/Documents/Code/TS/SplitDebt/frontend/` (vue-i18n → react-i18next adaptation)

## Global Constraints

- Default locale: `vi` (Vietnamese-first)
- Fallback locale: `vi`
- Locale files: `src/locales/vi.json`, `src/locales/en.json` — mirror key-for-key
- Key naming: `namespace.camelCaseKey` (e.g., `auth.emailPlaceholder`)
- Interpolation: named params `{email}`, `{name}`, `{count}`
- Persistence: `localStorage.getItem('lang')`
- `<html lang>` synced on locale change
- API header: `Accept-Language` from localStorage

## Review Focus

- Locale files must be perfect mirrors — missing key in en.json silently falls back to vi
- `t()` calls with wrong key names produce visible raw keys (`auth.wrongKey`) — type-safe keys preferred
- Language switch must update ALL rendered text without page reload
- `Accept-Language` header must reflect current locale, not stale localStorage

- [ ] **Step 4: Create `src/i18n.ts`**

```ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import vi from './locales/vi.json'
import en from './locales/en.json'

const savedLang = localStorage.getItem('lang') || 'vi'

i18n.use(initReactI18next).init({
  resources: { vi: { translation: vi }, en: { translation: en } },
  lng: savedLang,
  fallbackLng: 'vi',
  interpolation: { escapeValue: false },
})

export default i18n
```
